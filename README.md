# 🗺️ DWG WORKFLOW

AutoCAD uses **DWG** as its primary drawing format.

A typical workflow:

```text id="cadflow"
CONCEPT
   ↓
SKETCH
   ↓
2D / 3D MODEL
   ↓
ANNOTATION
   ↓
DOCUMENTATION
   ↓
REVIEW
   ↓
PLOT / EXPORT
```
